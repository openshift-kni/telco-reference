# Telco add-ons

This directory contains optional add-ons that can be deployed on top of one of the Telco Reference Design Specifications. These optional add-ons provide an opinionated method to deploy non-Telco applications on top of the RDS, and in some cases an add-on may be incorporated as part of the RDS specification in the future.

Refer to the individual README file on each directory for detailed information and installation instructions.
